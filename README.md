# GA-INSIGHT: 손해보험 법인대리점(GA) 통합설계 & 보장분석 솔루션

손해보험 법인보험대리점(GA)을 위한 **8대 주요 손해보험사 실시간 비교설계, 1초 고객 보장분석, 고객 상담용 맞춤 제안서(A4/PDF) 출력, 원수사 전산 연동(RPA)** 올인원 플랫폼입니다.

---

## 🚀 주요 핵심 기능

### 1. 8대 주요 손해보험사 실시간 동시 비교설계
* **지원 원수사 (8개사)**: 
  * 메리츠화재, 삼성화재, DB손해보험, 현대해상, KB손해보험, 한화손해보험, 흥국화재, 롯데손해보험
* **반영 계수**:
  * 고객 연령(만 나이), 성별, 직업급수(1~3급), 병력/심사유형(표준체, 간편 3.5.5, 간편 3.3.5)
  * 납입기간(20년납, 30년납 등) 및 만기(90세만기, 100세만기)
  * 각 원수사별 전략 담보 할인 및 요율 지수 실시간 산출
* **담보별 상세 매트릭스**:
  * 일반암, 유사암, 뇌혈관질환, 허혈성/심혈관질환, 질병 1~5종 수술비, 질병수술비, 상해수술비, 가족일상생활배상책임 등
  * 각 담보별 8개사 중 **최저가 자동 하이라이트(녹색 배지)** 및 종합 1~8위 랭킹 제공

### 2. 1초 고객 보장 분석 & 리모델링 진단 (Radar Chart)
* 고객의 기존 보험 가입 금액 입력 시 **8대 필수 보장 기준 대비 충족도(0~100점)** 산출
* 대화형 레이더 차트(Chart.js)를 통해 보장 불균형 시각화
* 부족한 담보(Gap)를 자동으로 추출하여 **원클릭으로 8개사 비교설계 엔진에 즉시 연동**

### 3. 고객 상담 및 브리핑용 비교 제안서 인쇄 (A4 / PDF)
* 웹 화면에서 즉시 확인 가능한 세련된 A4 규격 출력용 모달 지원
* 대리점 공식 상호, 등록번호, 담당 설계사 직통 연락처 자동 삽입
* 가성비 1순위 추천 플랜 + 2순위 균형 플랜 요약 및 8개사 담보별 월 보험료 비교표 포함
* 브라우저에서 `Ctrl + P` (인쇄 또는 PDF로 저장) 시 깔끔하게 1~2장 출력

### 4. 원수사 전산 자동화 (RPA) 브릿지
* **원클릭 클립보드 주입 데이터**: 각 원수사 전산에 복사-붙여넣기(Ctrl+V) 가능한 정형 포맷 제공
* **8대 원수사 전산 포털 바로가기**: 메리츠, 삼성, DB, 현대, KB 등 즉시 접속
* **Python Playwright 자동화 스크립트**: 실제 브라우저 자동 입력이 가능한 Python 코드 자동 생성 및 다운로드

### 5. 고객 데이터베이스 관리 (CRM)
* 가망 고객 인적사항, 직업, 병력 고지 유형 관리
* 고객별 비교설계안 저장 및 이력 관리

## 💻 실행 방법 (Windows)

### 방법 1: 원클릭 배치 파일 실행 (가장 간편)
프로젝트 폴더 내 `start_server.bat` 파일을 더블 클릭하면 브라우저(`http://localhost:8000`)가 자동으로 열리며 서버가 구동됩니다.

### 방법 2: 명령줄(CMD / PowerShell) 실행
```powershell
# uv 패키지 매니저로 실행
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
